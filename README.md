- **[S1GHT](https://github.com/Doga0/S1GHT)** — A framework for real-time visual decisions (jev-like) on images and video, combining vision models, object tracking, and calibrated predictions.

- **[EmbedTurk](https://github.com/Doga0/EmbedTurk)** — Research on Turkish text-embedding models, published at INFUS 2025.
- **[MaskDriven-SD](https://github.com/Doga0/MaskDriven-SD)** — A synthetic data generation pipeline using diffusion models and mask-based guidance.
- **[SerbestKategori-MedTurk](https://github.com/Doga0/SerbestKategori-MedTurk)** — A Turkish multimodal medical assistant developed for the TEKNOFEST Turkish NLP competition.
